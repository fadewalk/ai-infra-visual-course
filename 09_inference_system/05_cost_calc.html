价格战的锚点

API 定价即成本+毛利；四年 token 价格降了约百倍，靠的正是第 6/7 课那些架构与系统优化。

🧠 对应上游 12.2《AI Infra 入门讲座》的四层杠杆主线。

缓存命中是隐藏大杀器

Prefix Caching 命中时，输入 token 按折扣计费（部分厂商 1 折起）——Agent 多轮场景收益巨大。

🧠 类似 CDN 命中：不回源就几乎免费。

SRE 的翻译职责

把"SM Active 低/预留浪费/利用率 30%"翻译成"每月多烧 $X"——这是推动优化立项的最有效语言。
