三、四种策略对照表

策略切什么通信模式通信量典型用法
DP 数据并行不切模型，切数据AllReduce（每步同步一次梯度）大模型单卡放得下时，复制多份提吞吐
TP 张量并行每一层的权重矩阵切成 N 份AllReduce / AllGather（每层多次）最大单机 NVLink 域内（8 卡内）
PP 流水线并行按层切成 N 段点对点 Send/Recv（仅相邻段）最小跨机；生产常 TP(机内)+PP(机间) 混合
EP 专家并行MoE 的专家分布到不同卡All-to-All（token 按路由分发）中MoE 模型（DeepSeek / Qwen-MoE 等）
